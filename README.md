# Scam Job Recruitment Detection

### Detection of Fake Recruitment Emails Using Deep Learning

This project is designed to detect fake recruitment emails using a deep learning approach based on BERT, CNN, LSTM, and Attention mechanisms.

## Technologies Used

- Python
- BERT
- CNN
- LSTM
- Attention Mechanism
- HTML
- CSS
- JavaScript

## Project Structure

- `backend/` – Backend components
- `frontend/` – Frontend interface
- `model/` – Machine learning model files
- `requirements.txt` – Required Python packages

## How It Works

The system analyzes recruitment email content and uses a deep learning pipeline to identify potentially fake recruitment emails.

**BERT → CNN → LSTM → Attention**

## Purpose

The main goal of this project is to help identify fraudulent recruitment emails and provide a safer way for users to evaluate suspicious job-related messages.
